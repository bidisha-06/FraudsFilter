# 🛡️ FraudsFilter

### An Intelligent Fraud Detection and Prevention System

## 🚀 Project Overview

**FraudsFilter** is a web-based project designed to help users identify and recognize potentially fraudulent or suspicious online activities.

Developed using HTML, CSS, and JavaScript, the project focuses on providing an interactive and user-friendly interface for exploring fraud detection and digital security.

The application aims to promote safer digital interactions and improve awareness of potential online fraud.

## 🛠️ Technologies Used

- **HTML5** – Structure and content of the application.
- **CSS3** – Styling, layout, and user interface design.
- **JavaScript** – Interactive elements and application functionality.

## 📁 Project Structure

### 3. Launch the Application

Open `index.html` in your preferred web browser.

Alternatively, use Visual Studio Code:

1. Open the FraudsFilter folder in VS Code.
2. Install the Live Server extension.
3. Right-click `index.html`.
4. Select **Open with Live Server**.

## 💻 Requirements

- Modern web browser.
- Visual Studio Code (recommended).
- Live Server extension (optional).

**Note:** FraudsFilter currently uses vanilla HTML, CSS, and JavaScript. Node.js, npm installation, and `npm run dev` are not required.
